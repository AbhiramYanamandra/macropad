Macropad Studio · 3 design directions

A menu bar app plus an editor window. All three show the same content so you can compare them. None of this is built yet.

A · Native macOSLooks like it shipped with the Mac: translucent glass panels, SF Pro, system blue, and settings grouped the way System Settings does it. Light and dark mode.
B · Minimal + playfulA hardware-toy feel: a warm paper background, chunky rounded shapes, pastel keycaps and bouncy motion. Fredoka for headings, Nunito for text.
C · Retro / pixelBuilt around the OLED: phosphor green on black, pixel borders, Press Start 2P headings, VT323 text and a blinking cursor. The blinking stops when reduced motion is on.
